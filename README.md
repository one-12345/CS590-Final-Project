# CS590-Final-Project
Recreation of SHA-3 as an exercise in hashing algorithms.

Group: Shashwat Gupta, Michael Yang, Celine Zhang

To compile: javac SHA3.java
To run: java SHA3 input.txt

The input message to be hashed must be provided as a single-line string in a file provided as the first command line argument to the run command. An empty string can be represented as an empty line in input.txt. The output hash is written to a file named output.txt.
